### Current work
Current work at Bayer explores how uncertainty-aware machine learning can be integrated into real-world discovery workflows. 

Next steps include the integration of uncertainty-aware active learning methods into [MotherML](https://github.com/Bayer-Group/MotherML), Bayer's open-source machine learning framework for cheminformatics.
